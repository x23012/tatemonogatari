# たてものがたり アプリ（app/）

ビルド不要の静的Webアプリです。このフォルダをそのまま公開すれば動きます。

## 手元で試す
```
cd app
python3 -m http.server 8765
```
→ http://localhost:8765 を開く（スマホでの確認は同じWi-Fiで `http://<PCのIP>:8765`。ただしカメラとオフライン機能は https か localhost でしか動きません）

## 公開する
1. `app/` の中身を https のサーバーに置く（GitHub Pages、Netlify、Cloudflare Pages など。無料で可）
2. 公開URLが決まったら、カードのQRを作る：
   ```
   pip install qrcode pillow
   python tools/make_qr.py https://公開URL
   ```
   QRの中身は `https://公開URL/?card=<id>`。スマホのカメラで読んでも、アプリ内の読み取りでも追加されます。

## データを変えたとき
- `data/cards.json` と `photos/` はキット直下のものをコピーしています。直したら `app/data/`・`app/photos/` にもコピーしてください。
- `sw.js` の `VERSION` を1つ上げると、スマホに保存された古いデータが入れかわります。
- `lat` / `lng` を入れると、自動で「近い順に並べる」ボタンが出て、Googleマップにも座標で渡すようになります。

## カードを読むしくみ
「カードをカメラで読む」は、QRではなく**カードの見た目**で見分けます（`matcher.js`）。
1. 画面の枠にカードを合わせると、帯の色（＝点数）と、写真部分の色・明るさの並びを取り出す
2. 見本（`cards/<id>.jpg`：印刷データから切り出したカード画像）と比べ、近い順に並べる
3. 十分近く、2位との差がはっきりしていれば「このカードかな？」を出す。違うときは2位・3位から選べる

4. 同じ範囲を大きく（400px）切り出し、帯の下の線の本数を読む（`stripes.js`）。本数が合わない候補は後ろへ回す

- 位置のずれ（±5%）、大きさ（±10%）、さかさまも自動で試します。
- カードのデザインや写真を変えたら、`tools/card_images/` のスクリプトで `cards/` を作り直してください。
- `dev/test.html` は精度テスト用のページです（公開しなくてよい）。ずれ・暗さ・色かぶり・ぼけを加えた画像で正解率を測ります。
- QRが印刷されたカードは、Android Chrome ではアプリ内でもQRとして読めます（スマホのカメラアプリで読んでも追加されます）。

## 写真1枚でまとめて読む（`photoreader.js`）
ゲームの最後に、スタンプをのせたままのカードを並べて1枚撮ると、スタンプの数字（＝月）の順にルートを作ります。
1. スタンプ（白い紙の上の色つきの丸）を探す。机より明るい白い紙に囲まれた丸だけを数える
2. 丸の中の数字（1〜12）を読む。1人の数字は1枚ずつなので、色ごとに重ならないように割り当てる
3. スタンプのまわりのカードの輪郭を探し、帯が左右にくる向きにそろえる
4. スタンプの紙の白さで色かぶりを直し、スタンプで隠れた所をのぞいて見本と比べる
5. 元の大きさの写真から、カードの帯の下の線（左1〜3本・右1〜4本）を数え、本数が合わない候補を後ろへ回す。線のある側が下なので、上下の向きもここで決まる
6. 確認画面で、写真の切り抜きと見本を並べて表示。自信がない所は黄色。月とカードはその場で直せる

### 帯の下の線（ver17 のカードから）
- 帯の色（＝点数）と、左右の線の本数の組み合わせで、カードが1枚に決まります。本数は `data/cards.json` の `stripes`（[左, 右]）。
- 線は「濃い帯の中の明るい線」なので、照明の色かぶりがあっても数えられます。
- 線はカードの高さの約2.3%しかないので、写真の中でカードが150px以上に写っている必要があります（線が3px以上）。小さいときは線を使わず、これまでどおり模様だけで見分けます。
- 線の位置を変えたカードを作ったら、`stripes.js` の `SLOTS`（見本画像の中の線の位置）と、`stripes` の本数を直してください。`dev/stripe-test.html` で、見本・1枚ずつ・作った机の写真のテストができます。

- 写真はプレイヤーの席から撮る前提です（数字の6と9を見分けるため、数字はおおむね上向きとして読む）。
- `dev/photo-test.html` で、写真ごとの読み取り結果（スタンプ・数字・カードの候補）を確かめられます。試した写真は `dev/samples/`（git には入れない）。

## ファイル
| ファイル | 内容 |
| --- | --- |
| index.html / style.css / app.js | アプリ本体 |
| matcher.js | カードの見た目で見分ける処理 |
| stripes.js | 帯の下の線の本数を読む処理 |
| photoreader.js | 写真1枚から、スタンプの月とカードをまとめて読む処理 |
| cards/ | 見分け用のカード画像（印刷データから切り出し） |
| dev/test.html | 見分けの精度テスト（開発用） |
| dev/photo-test.html | 写真まとめ読みのテスト（開発用） |
| dev/stripe-test.html | 帯の下の線のテスト（開発用） |
| sw.js / manifest.webmanifest / icon* | ホーム画面に追加・オフライン用 |
| data/, photos/ | カードデータと写真（キット直下のコピー） |
